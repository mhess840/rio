Command to start:

POLICY=Pi05LerobotCfg uv run --group pi --no-group docs -m examples.policy_inference   --policy-path ckpts/pi05   --instruction "pick up the blue object and place it on the red plate"   --policy-cfg.device cuda:1   --diag-dir /tmp/pi05_diag/run2








Konvertirungs command: uv run python -m examples.data.convert_to_lerobot_pi05 \
  --input data/kassow_vive_gripper \
  --output data/lerobot/kassow_pi05_pick_notrim \
  --tasks data/kassow_vive_gripper/tasks.yaml \
  --repo-id local/kassow_pi05_pick_notrim \
  --clean \
  --no-trim-idle \
  --workers 6
